## 📝 AI 简历分析 + 岗位匹配系统

**一个基于 Spring Boot + Vue3 的智能简历分析全栈项目**

### 🎯 项目简介

AI 简历分析与岗位匹配系统是一个能够**智能分析简历、匹配岗位**的求职辅助工具。用户上传简历后，AI 会自动提取结构化信息（技能、工作经历、教育背景等），并与岗位 JD 进行多维度匹配，生成匹配度评分和优化建议。

### 🛠 技术栈

**后端**
- Spring Boot 3.2 + MyBatis Plus
- MySQL 8.x + Redis
- JWT 认证

**前端**
- Vue 3 + Composition API
- Element Plus + Pinia + Vite

### ✨ 核心功能

- 📤 **简历上传** - 支持 PDF/DOCX/TXT 格式
- 🤖 **AI 智能分析** - 自动提取技能、经历、教育背景
- 🔍 **岗位匹配** - 多维度计算匹配度评分
- 💡 **优化建议** - 生成针对性的简历优化意见

### 🚀 项目亮点

1. **AI 智能分析** - 接入大模型 API，实现简历结构化提取
2. **多维匹配** - 基于技能、经验、学历等多维度计算匹配度
3. **完整业务流** - 从简历上传到匹配结果，形成闭环
4. **工程化设计** - 分层架构、缓存优化、异步处理
